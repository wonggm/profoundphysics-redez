# Profound Physics — Brand Assets

This directory holds the brand glyph and social card for the site.

## Files

- **`spike-mark.svg`** — The 4-spoke radial asterisk brand glyph (the "spike mark"). Uses `currentColor` so it inherits the surrounding text color, making it usable on both light and dark surfaces.
- **`favicon.svg`** — The spike mark on the cream canvas, in coral, sized for browser favicons.
- **`og-image.png`** — A 1200×630 social card used for link previews (Open Graph + Twitter Card). If absent, the spike-mark SVG is the fallback for some clients.

## Design rationale

The spike mark is a stylized asterisk: four tapered diamond spokes radiating from a single point at 90° intervals. It evokes:

- A particle collision (the four "jets" of an event)
- A coordinate system (the four axes of a 2D plane)
- A punctuation glyph (the asterisk), which the Profound Physics brand uses to mean "a mark, a callout, a place to look"

It is intentionally simple so it reads at any size — from a 16×16 favicon to a 200px wordmark prefix.
